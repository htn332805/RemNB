# 🚀 AIOS Learning Adventure — Tutorial Series

**Who is this for?** Anyone who is curious about AI — even if you have never written a single line of code!  
**Best age:** 8–12 years old (younger kids: ask a grown-up to sit with you 😊)  
**What you will learn:** How to use your own AI helper to read documents, take smart notes, build a knowledge treasure box, and ask your AI clever questions using what it already knows.

## Before You Start

Make sure a grown-up has already set everything up. The system needs:
- The **AIOS Agent** to be running (you will check this in T00)
- The **Qdrant** memory database to be running
- An **Obsidian vault** folder ready inside the project

If anything is broken, the tutorial will tell you exactly what to look for.

## Words You Will Learn

| Word | What it means |
|---|---|
| **AI** | A computer program that can understand and respond to your writing |
| **Agent** | The AIOS brain that receives your questions and does the work |
| **Vault** | A folder of smart notes, like a treasure chest for knowledge |
| **Obsidian** | A note-taking app that lets you connect notes like a spider web |
| **Qdrant** | A special memory database that remembers things by meaning, not just words |
| **Summary** | A short version of something long — the "highlights" |
| **Context** | Extra information you give the AI so it can give a smarter answer |
| **Command** | A line of text you type to make the computer do something |
| **Endpoint** | A door into the AI — you knock on it by sending a command |
| **SSH** | A secret tunnel for sending commands to a remote computer |
| **Shell script** | A list of commands saved in a file, run in order automatically |
| **tmux / screen** | Tools that keep programs running on a server even if you disconnect |
| **Cron** | A scheduler that runs tasks at a set time, like an alarm clock |
| **Pipeline** | A chain of steps where each step's output feeds into the next |
| **Journal** | A diary the pipeline writes about what it did and whether it succeeded |
